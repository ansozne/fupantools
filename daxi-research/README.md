# Daxi 金融研究框架 · 项目概览

## 解决的问题

将个股深度分析、行业景气跟踪、证据核查、观点表达与组合决策支持组织为可复核的工作流，避免无来源的事实陈述与跨期数据混用。原项目本地保留了多个版本的分析规范与行业研究辅助代码；这里仅公开**架构概览**，不复制原始脚本与客户或个人研究报告。

## 已有模块与研究流程

1. **输入与标的确认**：确认证券代码、市场、报告日期及分析问题。
2. **资料与指标采集**：将行情、财报、行业与公告等材料区分来源与时点；缺失项显式留空。
3. **行业与公司分析**：将行业景气、公司基本面、估值、催化与风险分别成章，不以单一打分替代论证。
4. **多版本分析框架**：本地存在 v2 至 v5.1 方法文档及更严格的金融分析质量门禁文档；此公开概览不宣称所有版本均已完成自动化部署。
5. **证据与交付检查**：使用明确日期、证据编号与缺失标识，区分事实、估计和观点；对冲突来源保留说明。

## 范围与限制

- 这是一份**项目案例说明**，不是可运行软件或经审计的投资产品；原有第三方数据接口及授权不可从本仓库获得。
- 出于凭据、个人隐私和资料来源权属审查，行业工具原脚本、个股报告、数据 JSON、日志、接口配置与历史结果均未纳入。
- 无公开可重复的收益或回测样本，因此不在此展示收益率、胜率或投资绩效。
