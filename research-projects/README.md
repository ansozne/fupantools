# 主线跟踪与板块新高研究 · 项目概览

以下项目在本地有实际研究脚本；板块新高方向额外公开 [脱敏离线回测子集](sector-new-high-backtest/README.md)，不公开原始数据库、缓存、个人配置或未经脱敏的生产脚本。

## 主线雷达

本地模块包含每日统一入口、主线发现器与跟踪器：更新已有主线状态，识别新触发的概念是否与既有主线重叠，区分延续、分支、新主线和退潮，并输出分层观察结论。它是一套**研究工作流**，不是经过独立验证的交易建议。

## 板块新高研究

本地模块覆盖板块数据采集、新高比例、信号统计、阈值敏感性、龙头新高、成交过滤、每日扫描和候选筛选等步骤。已有脚本使用本机历史库路径与外部数据源；未经授权的源数据、信号文件与结果不会入库。**本仓库未发布真实行情下可复现的回测结果**，不声称任何胜率或收益率。

后续若公开源码，应先将路径、数据许可、授权接口与推送目标参数化，提供合成数据测试与独立安装说明。
