# 板块接近新高：离线研究脚本（脱敏版）

仅用于方法研究，**不附带任何历史数据、成分股快照、实盘记录、绩效报告或已验证收益**；不自动下载、推送或交易。该包保留核心四段：接近新高比例计算、信号与前瞻统计、阈值敏感性、板块内弱势股比较。实时抓取、日常扫描、外发及后续扩展模型不在本包内。输出只写本地 `BACKTEST_DATA_DIR`。

## 环境与输入

Python 3.10+；`pip install numpy pandas pyarrow`（请在自己的环境按合规流程安装）。自行取得并确认有研究使用授权的前复权日线 CSV：`STOCK_DATA_DIR/000001_qfq.csv` 等，列名 `日期,收盘`，日期可由 pandas 解析、价格为正。`BACKTEST_DATA_DIR/sector_constituents.json` 为 `{ "板块名": ["6位股票代码", ...] }`；成分股数据须自行取得并确认授权，**不能把现有私有快照直接作为公开包提交**。数据源、复权口径、停牌与退市股票处理及时间戳应由使用者自行记录。源脚本以申万行业口径为例，换用其他板块分类不保证可比。

路径从环境变量配置（可选），默认输入 `./input/stocks/`、数据及输出 `./data/`；脚本目录以文件本身定位，不依赖个人目录。无需任何 API 凭据，不配置外发目标；没有网络调用。请勿将授权数据、生成结果或密钥提交到公开仓库，见 `.gitignore`。

以下命令须在此目录执行（或先 `cd` 到本目录）：

## 流程与口径 / 局限

- 01：2020-01-01 起计算各股**当日收盘**相对包含当日的 250 个有效交易日滚动收盘最高值的距离，≤5% 算接近新高；板块内比例。只保存比例大于零的日期。与原始研究代码相比，此公开版修正无足够历史/缺价时被布尔 False 误计入分母的问题；因此数字**不能视为原版回测复现结果**。开始日期先截断再滚动，最早需积累 250 个观测值，非从 2020 年第一天有信号。
- 02：比例≥20% 且同板块距上次事件至少 60 **自然日**为触发；使用成员股日收益等权均值复合估算板块未来 30/60/90 个交易观测的收益、回撤。触发日收盘价才能确定信号，代码的触发日净值归一化不是可交易买入价；不含费率、冲击、停牌约束。
- 02b：比较 15% 至 50% 多个阈值；多重试验或择优阈值有过拟合风险，**不能据此声称稳定有效**。
- 03：在触发日按近 60 个观测涨幅选最弱 5 只，对比板块全体等权、之后 40 个观测的收盘到收盘收益；同样不是严格次日可成交回测，实际买入价格与可交易性未建模。

重大潜在偏差：当前成分股快照回看历史存在幸存者/未来信息偏差；前复权历史价若以未来除权因子重算也须审计；数据缺失、行业调样、重复股票、市场停牌和上市时间影响分母及收益；不同 CSV 日期不齐、事件重叠使样本不独立。未做逐日历史成分重建、严格逐日无前视撮合、数据授权核验、交易费用/风险控制和真实市场表现复核。合成单测只检查少量计算路径，并非真实行情或收益验证。输出数字仅代表使用者提供数据和此口径下的统计，不构成投资建议。
